# 冬日旅行 2026—2027

独立页面：https://diw1.github.io/family-china-trip-2026/winter-2026/

本目录保留本次冬季规划，不覆盖九月旅行。`index.html` 为路线约束、签证、从化与官方来源，`app.js` 为双版本首尔安排、日期联动、酒店候选和待办；`style.css` 为响应式样式。更新日期和政策来源需要一起修改。

- `?party=couple&date=22`：两人首尔，12/22–28。
- `?party=family&date=23`：亲子首尔，12/23–29。
- 仅日期和人数选项写入分享链接；待办只用本机 localStorage，不上传。
- 全部为规划，无机票或酒店已订信息，无申请已递交信息。
- 费用表：墨尔本领馆 C-3 页面附带 VISA FEE (01.JAN.2025).pdf，已读图核对中国国籍单次短期 A$60。
- 用户已确认：孩子七岁，已有中国签证；中国护照持有人是澳洲 PR。孩子不按中国 30 天免签规划。
- 仍需核对：现有签证停留期及可用入境次数、PR 返澳 travel facility、在澳连续居住证明、孩子不去韩国时的照顾安排。
- 酒店只有官网房型核查，无具体日期成交价格；签证和航班须在出发前复核。
